# Screenshot checklist for submission

Capture these screenshots after running the project locally:
1. Registration or login screen.
2. Main dashboard showing the three encryption strategy cards.
3. AES encryption screen with a selected test file.
4. ECC encryption screen.
5. Hybrid AES–ECC encryption screen.
6. Decryption screen.
7. Successful encrypted-file download and successful recovered-file download.
8. Key management screen.
9. File activity and audit history screens after a successful operation.
10. Pytest terminal output showing the complete test run.
11. Locust Statistics tab after a completed test (include users, requests, failures, median/average response time and throughput).
12. Locust Charts tab from the same run.

For performance screenshots, record the machine, Python version, test duration, number of users, spawn rate, and file size. Do not claim a performance test passed until you have run it and saved the actual results.

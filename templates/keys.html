Key management.

Understand how SecureVault creates, derives, protects and uses keys in each strategy.

◈STRATEGY 01

AES-256-GCM

A password-derived 256-bit key is generated using scrypt with a random salt. A fresh nonce and authenticated-encryption tag are used for each file.

Scrypt KDF256-bit keyRandom salt
⌘STRATEGY 02

ECC-based ECDH

Ephemeral P-256 elliptic-curve keys establish a shared secret. HKDF derives an AES-GCM key. The recipient private key is password-protected in the file container.

ECDHHKDF-SHA256P-256
✳STRATEGY 03 · FEATURED

Hybrid AES–ECC

A random AES-256 key encrypts the file. ECDH and HKDF derive a separate key that wraps the random AES key with AES-GCM. This separates data encryption from key protection.

Random AES keyECDH key wrappingDual GCM tags
⚠
Demo security boundary

The encrypted container includes the password-encrypted private key required for this self-contained educational workflow. For production, use a recipient-managed public/private key system, external key storage, strict CSRF controls, rate limiting, secure secret configuration and a security review. Never treat this demo as a certified file-vault product.
